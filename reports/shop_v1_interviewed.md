# 仕様の漏れ検査：通販の返品（会話で答えた版）

判定：**受け入れ可**（拒否 0 件・確認 5 件・記録 0 件）

## 確認：人が判断する項目

1. **操作「重複した発送を記録する」を行うユースケースがありません**
    - 問い：「重複した発送を記録する」は誰がどの場面で行いますか
2. **画面の流れ「購入者の画面」の画面 申込完了 から先へ進む操作も戻る操作もありません**
    - 問い：申込完了 を見たあと、利用者はどこへ行けますか
3. **ユースケース「不正な注文を確かめる」を始める画面上の操作がありません**
    - 問い：「不正な注文を確かめる」はどの画面から始めますか（画面を持たない処理なら、その旨を確認してください）
4. **操作「不正な支払を記録する」で、取り消せない 不正な注文の通知 の前に確認の手順がありません**
    - 問い：不正な注文の通知 を実行する前に、内容を確認する手順を挟みますか
5. **操作「重複した発送を記録する」で、取り消せない 重複した発送の通知 の前に確認の手順がありません**
    - 問い：重複した発送の通知 を実行する前に、内容を確認する手順を挟みますか

## 問題がなかった検査

- 出力の割り当て
- 決定表の網羅と排他
- 性質の矛盾と決定表との整合
- ルールと決定表の整合
- 状態と出来事の網羅
- 失敗の扱いの網羅
- 入力項目の使用
